Wishlist Stock Tracker — Project Summary

Daily NSE wishlist monitor → one PDF report → Telegram. Runs free on GitHub Actions.

1. Architecture

GitHub Actions (cron: Mon–Fri 6:00 PM IST)
      ↓
Data Fetch Layer
   1. YahooFinanceProvider  (yfinance ticker.history — 0.2.x & 1.x safe, retry ×3)
   2. YahooChartAPIProvider (direct Yahoo v8 chart REST fallback)
   3. Persistent cache      (data/cache.json, last good value)
      ↓
Validation (price > 0, 52W high > low) → Opportunity Scoring
      ↓
PDF Report (reportlab): summary page + sector tables
      ↓
Telegram sendDocument (text message as fallback)

3. Reliability layers

Layer 1 — yfinance
Polite 0.3s spacing between symbols, 3 attempts with 1s/2s backoff. "Possibly delisted" from Yahoo is usually throttling; a retry fixes it.
Layer 2 — Yahoo v8 chart REST
Calls query1.finance.yahoo.com/v8/finance/chart/.NS?range=1y&interval=1d directly. Library-independent, so a new yfinance release can't break the pipeline.
Layer 3 — Cache
data/cache.json keeps the last good value per symbol. If a stock is temporarily unfetchable the PDF shows its last known price tagged [CACHED].
Delivery fallback
If the PDF can't be sent (or reportlab missing), a formatted plain-text message is delivered instead. Caption always shows Live X/27.
