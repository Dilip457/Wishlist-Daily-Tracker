📊 Wishlist Stock Daily Tracker — Complete Project Summary

Prepared: 25 Sep 2026  |  GitHub Repo: github.com/Dilip457/Wishlist-Daily-Tracker

Purpose: This document covers everything from A to Z — project goal, code structure, what was built, what works, what doesn't, and the exact technical issue blocking full functionality.

1. Project Goal

Build an automated daily alert system that:

  • Tracks 27 wishlist stocks across 20 sectors (from the rebalanced stock list image)
  • Shows for each stock: Current Price, 52W High, % below 52W High, 52W Low, Day Change %, Day High/Low
  • Detects if a stock hits a new 52W High or Low today and flags it
  • Generates 4 sector-group PNG images (~900×900 px each, readable on mobile)
  • Sends images to a Telegram group automatically every weekday at 6:00 PM IST
  • Runs on GitHub Actions (free, no server needed)
  • Uses NSE India official API as data source

4. How the Script Works (Flow)

GitHub Actions (cron: Mon–Fri 6:00 PM IST)
      │
      ▼
Step 1: Build NSE Session
  → Visit https://www.nseindia.com  (sets initial cookies)
  → Visit https://www.nseindia.com/market-data/live-equity-market
  → Session now has cookies: _abck, bm_sz, browse-url

      │
      ▼
Step 2: Fetch Stock Data
  → For each index in [NIFTY 500, NIFTY MICROCAP 250]:
      a. Visit index page (sets Referer cookie)
      b. Call equity-stockIndices API
      c. Get list of stocks with: lastPrice, yearHigh, yearLow,
         dayHigh, dayLow, pChange, previousClose
  → Build master_lookup {symbol: data}
  → Map 27 wishlist symbols to their data
  → Calculate: pct_from_high, pct_from_low, new_52w_high, new_52w_low

      │
      ▼
Step 3: Build 4 PNG Images
  → Part 1/4: Beverages | Power | Exchange | Shrimp | Auto
  → Part 2/4: Fertilizer | Cable | Hospitality | Pharma | Capital Goods
  → Part 3/4: IT | Auto Ancillary | Semiconductor | Space | Drone
  → Part 4/4: Data Center | Banking | Defence | Hospital | Consumer
  → Each image: ~900×900 px, dark theme, color-coded dip signals

      │
      ▼
Step 4: Send to Telegram
  → sendPhoto API for each of 4 images
  → Caption: "Wishlist Stock Tracker — Part X/4 | Date"
  → Falls back to text message if image fails

7. ⚠️ THE CORE ISSUE — NSE API Blocking

Root Problem: NSE India uses Akamai Bot Manager to protect their API endpoints. GitHub Actions IPs and certain corporate networks are detected as bots and blocked.

7.3 Why allIndices Works But Others Don't

EndpointWhy It Works/Fails
allIndicesSimple public endpoint, NSE doesn't restrict it. Returns index-level data only (Nifty 50 value, not individual stocks).
equity-stockIndicesReturns individual stock data. NSE restricts this endpoint more aggressively. Returns 404 (Akamai blocking with fake 404).
quote-equityReturns individual stock data. Blocked with 403 from GitHub Actions IPs.

7.4 The Akamai Bot Manager Problem

NSE uses Akamai Bot Manager which:

  • Detects automated requests based on IP reputation, request patterns, missing browser fingerprints
  • GitHub Actions IPs are in Akamai's "known bot" list → blocked
  • Corporate network IPs (Qualcomm) may also be partially blocked
  • allIndices is whitelisted (public data, NSE wants it accessible)
  • Individual stock endpoints are protected (more sensitive data)

9. Possible Solutions (For Your Review)

Option A — Yahoo Finance (yfinance library) RECOMMENDED

How: Use yfinance Python library. NSE stocks have .NS suffix on Yahoo Finance (e.g., RADICO.NS). Returns same data: price, 52W high/low, day change.

Pros: 100% reliable from GitHub Actions, no session/cookie management, free, returns all required fields.
Cons: Data comes from Yahoo Finance (which sources from NSE), not directly from NSE.
Data accuracy: Same as NSE — Yahoo Finance mirrors NSE data in real-time.

Change needed: Add yfinance>=0.2.40 to requirements.txt. Replace fetch_equity_index() with yfinance calls. 
# Example yfinance usage:
import yfinance as yf
ticker = yf.Ticker("RADICO.NS")
fi = ticker.fast_info
price    = fi.last_price          # current price
high_52w = fi.fifty_two_week_high # 52W high
low_52w  = fi.fifty_two_week_low  # 52W low
day_high = fi.day_high            # today's high
day_low  = fi.day_low             # today's low
prev_cls = fi.previous_close      # previous close

Option B — Fix NSE equity-stockIndices with correct URL

How: The equity-stockIndices endpoint might work with a different URL format or index name. Need to find the exact URL NSE uses in their website's network requests (browser DevTools).

To investigate: Open Chrome DevTools → Network tab → Visit nseindia.com/market-data/live-equity-market → Look for XHR calls to find the exact API URL.

Pros: Uses NSE directly.
Cons: Might still be blocked from GitHub Actions IPs even with correct URL.

Option C — Use NSE's allIndices + Sector Index approach

How: allIndices works and returns 139 indices. Some sector indices (NIFTY BANK, NIFTY IT, NIFTY AUTO, etc.) contain our stocks. If equity-stockIndices works for sector indices (not broad indices), we can fetch sector-by-sector.

Pros: Uses NSE directly, allIndices is proven to work.
Cons: equity-stockIndices returns 404 for all index names tested. Might not work.

Option D — Use NSE's pre-open market data

How: https://www.nseindia.com/api/market-data-pre-open?key=ALL returns pre-open data for all stocks. Might include 52W high/low.

Pros: Single API call for all stocks.
Cons: Untested. Might not have 52W high/low. Might also be blocked.

Option E — Use BSE API

How: BSE has a public API. Requires BSE scrip codes instead of NSE symbols.

Pros: Different server, might not be blocked.
Cons: Need to map NSE symbols to BSE scrip codes. More complex.

12. Reference — Existing Working Project

The existing market_alert.py (in the parent repo) works successfully on GitHub Actions. It uses:

  • Endpoint: https://www.nseindia.com/api/allIndices
  • Data: Index-level data (Nifty 50, Midcap 150, Smallcap 250 values + 52W high/low)
  • Session: Same 4-header approach, visits homepage + equity market page
  • Output: Single PNG infographic sent to Telegram
Key difference: market_alert.py tracks indices (Nifty 50 value). The wishlist tracker needs individual stock data (RADICO price, TATAPOWER price, etc.). NSE's individual stock endpoints are blocked from GitHub Actions.
